# Jakarta Faces logo

The mark is a solid with three visible faces.
It takes the name literally, and shows parts composed into one whole, like a component tree rendered into a page.

## Files

- `faces-icon.svg`: the mark alone on a square canvas, for light backgrounds. Use it for favicons, avatars and anything below 64 px.
- `faces-icon-dark.svg`: the same for dark backgrounds.
- `faces-logo.svg`: the mark with the wordmark, for light backgrounds.
- `faces-logo-dark.svg`: the same for dark backgrounds.

## Colors

The colors are those of the Jakarta EE schooner logo: amber `#FDB940` on top, orange `#F98200` on the left, navy `#1B208B` on the right.
The wordmark is gray `#58585A`.
On dark backgrounds the navy face and the wordmark are white.
The gaps between the faces are transparent, so they show the background.

## Typeface

The wordmark is set in [Plus Jakarta Sans](https://github.com/tokotype/PlusJakartaSans) (SIL Open Font License): "JAKARTA" in Bold, "Faces" in ExtraBold.
It is converted to outlines, so the SVG files do not need the font.

## History

The Jakarta EE schooner logo belongs to the Eclipse Foundation, and nobody may alter it without the Foundation's permission.
Jakarta specification projects have no logo derived from it: each shows the plain schooner on its Eclipse project page.
The Jakarta Faces logo is therefore a standalone mark.

JavaServer Faces had its own logo.
Spec lead Ed Burns ran a community contest for it in 2011 ([#980](https://github.com/jakartaee/faces/issues/980)), and Wilber Saca won.
Entrants signed the Oracle Contributor Agreement, so the rights went to Oracle.
The logo carries the Oracle trademark "JavaServer™".
It lived only on the java.net project site ([archived copy](https://web.archive.org/web/20140222125011/https://javaserverfaces-spec-public.java.net/nonav/images/20110510-jsf-logo.png)), not in the source repository that Oracle transferred to the Eclipse Foundation.
It is therefore not part of Jakarta Faces.
